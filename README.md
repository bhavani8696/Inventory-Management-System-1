# Inventory Management System 1

Flask inventory marketplace with:
- Login/Register
- Dashboard
- Search and category filter
- 3-column product grid
- Product details
- Wishlist
- Add to Cart
- Admin-only Add/Edit/Delete
- SQLite database
- Render-ready gunicorn configuration

## Run locally
```powershell
cd Inventory-Management-System-1
python -m pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

The first registered account is the admin account.
